Project 02

FoodShare

Full-Stack Food Distribution Platform

FoodShare is a full-stack food distribution platform connecting donors and volunteers through structured food listing, pickup, and delivery workflows.

View Live Project → GitHub

Problem

Surplus food and people who can move it rarely share one workflow.

Donors need a way to list food with urgency. Volunteers need a way to claim, pick up, and deliver. Without a shared status model, coordination falls back to chats and spreadsheets.

Users

Donors

Restaurants, caterers, and individuals posting surplus food with time sensitivity.

Volunteers

People claiming listings and coordinating pickup and delivery.

Workflow

Listing → claim → delivery.

Surplus posted → Volunteer claimed → Out for delivery → Delivered

Urgency is grouped by expiration window (critical, high, medium, low) so volunteers can prioritize what moves first.

UI

Role-based entry, then a working dashboard.

The live product opens on authentication, with demo paths for donor and volunteer so the two dashboards can be reviewed without a full account setup.

Responsive Design

The interface is built as a mobile-first web app. Primary actions stay full-width on small screens; maps and listings stack instead of competing for a desktop grid.

Implementation

Front-end, maps, and a small API.

  • Responsive interface
  • Role-based dashboards
  • Location-based coordination
  • JavaScript
  • Leaflet.js
  • REST APIs
  • Node.js
  • SQLite

A static GitHub Pages build is available for review. The Node/SQLite API is used for local full-stack runs.
